# Segura Rent A Car + Taxi Segura

Sitio web de los dos negocios de Juan Segura en Esquel, Chubut: Segura Rent A Car (alquiler de Volkswagen Polo) y Taxi Segura.

Es una versión moderna del primer sitio del cliente. Al ingresar se elige el servicio, Rent A Car o Taxi, y cada uno tiene su propia presentación y contacto directo por WhatsApp, además de un formulario de consulta.

## Tecnologías

- Next.js
- TypeScript
- Sitio estático, sin base de datos
- Optimizado para SEO y posicionamiento en Google

## Despliegue

Cloudflare Pages.
